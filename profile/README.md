### Simplicity Idea Tech: small free tools from our work

- [tally-check](https://github.com/SimplicityIdeaTech/tally-check): prove a data migration lost nothing: counts, totals, missing and changed rows, tie-out CSV.
- [mail-dns-check](https://github.com/SimplicityIdeaTech/mail-dns-check): checks your domain's SPF, DKIM, DMARC and MX records and says, in plain English, what to fix.
- [backup-verify](https://github.com/SimplicityIdeaTech/backup-verify): checks whether a backup folder is still trustworthy: checksums, freshness, rsync exit codes.
- [iscc-plausibility-check](https://github.com/SimplicityIdeaTech/iscc-plausibility-check): offline pre-audit plausibility check for an intake CSV. Not an official ISCC tool.
